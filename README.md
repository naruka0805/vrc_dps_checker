# EclipticaOverlay

VRChatワールド「ECLIPTICA」専用の、ステージ／ボス戦単位でDPS・被ダメージ・履歴を表示する常時最前面のオーバーレイツール。

汎用のVRChat DPSチェッカーではなく、ECLIPTICAが実際に出すログ（`now in stage` / `now fighting boss` / `now in lobby` など）をそのまま使ってステージの区切りを判定している。

## できること

- **リアルタイムDPS/DTPS** — 直近10秒間の実測値（戦闘全体の平均ではなく、文字通り「秒間ダメージ」）
- **ステージ単位の集計** — 現在のステージ名・ラン進行度(%)・クラス名・戦闘状態（探索中/ボス戦/ボス撃破/休憩所）
- **HISTORY** — 直近のステージ履歴を古い順に表示。全滅したステージは行全体が赤文字になる
  - ボス撃破後の「休憩」に入った時点でその場でHISTORYを確定させる（次のステージ読み込みを待たない）
  - ゲーム自身が報告する「ボス単体への合計ダメージ」を`合計(ボス単体)`の形で答え合わせ表示
  - 同じセッション（ラン）中であれば、アプリを再起動してもHISTORYを保持する（`state.json`に保存）
  - セッションIDが変わったら（＝新しいランが始まったら）自動でリセット
  - クリックして開閉可能
- **PARTY共有（任意）** — 別途起動する`server.py`経由で、同じVRChatインスタンスにいる仲間とDPS/合計ダメージ/ボス単体ダメージをリアルタイム共有
  - No順/名前順/DPS順/トータルダメージ順で並び替え可能
  - 自分の行は色分けして常に先頭に表示
- **ウィンドウ操作** — 好きな位置へドラッグ移動、右クリックで設定/リセット/終了

## 起動方法

```bash
python ecliptica_overlay.py
```

パーティ共有を使う場合は、誰か1人が別途バックエンドを起動しておく（同じLAN内ならそのまま、外部の友達と繋ぐ場合はCloudflare Tunnel等が必要）。

```bash
python server.py
```

## 設定（右クリック→設定）

| 項目 | 内容 |
|---|---|
| ログフォルダ / ファイル名パターン | 通常は自動でVRChatの`AppData\LocalLow\VRChat\VRChat`を検知するので変更不要 |
| 与ダメージ/被ダメージの正規表現 | ECLIPTICA以外のワールドに転用する場合に変更 |
| 履歴に残すステージ数 | HISTORYの保持件数（デフォルト15） |
| パーティ共有バックエンドのURL / 送受信間隔 | `server.py`のURLと報告頻度（秒） |

設定は`config.json`に、HISTORYの保存状態は`state.json`に保存される（どちらもgit管理対象外）。

## 既知の制約

- アプリは**起動後に追記されたログ行だけ**を処理する。ただしインスタンスID・自分の表示名・現在のステージ/ボスの文脈は、再起動時にログ全体から復元される（ダメージ自体は遡って数えない）
- VRChatを`--enable-udon-debug-logging`起動オプション無しで起動していると、ECLIPTICAの戦闘ログが一切出力されないため、このツールは動作しない
- トークン等の「拾った瞬間」を示すログはECLIPTICA側に存在しないため、取得漏れの検知はできない
- PARTY共有は、相手も同じアプリを起動してバックエンドに報告していないと数値が出ない（ログから名前だけは分かるが、ダメージ量は分からない）

## ファイル構成

- `ecliptica_overlay.py` — クライアント本体（オーバーレイUI・ログ解析）
- `server.py` — パーティ共有用の最小構成バックエンド（FastAPI）
